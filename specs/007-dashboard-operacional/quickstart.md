# Quickstart: Dashboard operacional

1. Abrir um turno e concluir vendas em formas de pagamento diferentes.
2. Ajustar um produto até o estoque mínimo.
3. Acessar `/` e reconciliar indicadores, caixa, alertas e vendas recentes.
4. Fechar o turno e atualizar o dashboard para conferir o estado fechado.
